
# SCHEMA (Cấu Trúc Hệ Thống)

## 1. ENGINE (Toolkit)
*   `types`: Primitives.
*   `consts`: Physics.
*   `codec`: Bitwise ops.
*   `memory`: Static pools.
*   `space`: Topology.
*   `flow`: State mutation.
*   `rules`: Game laws.
*   `generate`: Move gen.
*   `score`: Evaluation.
*   `search`: Intelligence.
*   `query`: Meta-analysis.

## 2. WORKER (Concurrency)
*   `boot`: Entry point.
*   `protocol`: Message types.

## 3. UI (View)
*   `Arena`: Main stage.
*   `Unit`: Piece render.
*   `Slot`: Zone render.
